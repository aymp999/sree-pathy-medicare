# Sree Pathy Medicare

Mobile-friendly static website for medical and healthcare supply enquiries.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to finish publishing.

Expected project URL: https://aymp999.github.io/sree-pathy-medicare/

## Before business launch
- Add verified business phone, email, address and a working enquiry channel.
- Confirm all applicable licences and legal requirements before listing or supplying regulated products or medicines.
- Add only verified products, stock, pricing, claims and certificates.

The enquiry form currently prepares a message in the visitor's browser; it does not send or store submissions.
